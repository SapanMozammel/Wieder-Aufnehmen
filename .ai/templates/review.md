# Review

Task: project task path
Reviewer/tool: name and version; independent or self-review
Scope: diff or affected paths

## Findings

For each finding: severity, location, trigger, impact, evidence, remediation and
verification status. Distinguish blockers from suggestions.

## Verification

Checks performed and results; unavailable checks and residual risk.

## Decision

Ready, changes required or blocked, with rationale. Review is not authorization
to commit, push, publish or deploy.
