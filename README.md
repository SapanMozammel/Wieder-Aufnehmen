

# Package Management
- This project uses pnpm as the package manager instead of npm for all package management operations including install, add, remove, run scripts, build, dev, test, etc.

# Linting and Formatting
- This project has an existing formatter and linter configuration system in the `.formatter/` directory that should be analyzed, improved, and integrated with the current tech stack and pnpm workflow.

# Script Management
- User prefers to minimize `package.json` scripts and reduce cognitive load for developers by consolidating functionality into existing commands rather than having many separate scripts, while preserving essential safety and validation features.
